# 一键打开微调模型

双击项目根目录的 **启动决策模型.cmd**，工具会自动准备运行环境，再打开本机“决策工作台”。支持 Windows 10/11 x64，无需预先安装 Python 或手动启动接口。

## 首次启动与自动安装

1. 检查现有项目环境和 Python 3.11；缺少时自动下载 Python，并创建 `.venv`。
2. 检查固定版本依赖和实际导入情况，安装缺失依赖；环境已齐全时跳过下载和安装。
3. 首次安装 PyTorch 时，有可用 NVIDIA 驱动则选择 CUDA 12.8 版，否则选择 CPU 版。已有兼容版本会直接复用。
4. 检查通过后启动网页服务，自动打开浏览器并加载本地完整微调断点。

首次安装需要联网，窗口会显示当前步骤和下载、安装进度。Python 包约 25 MB；CPU 版 PyTorch 约 114 MB，CUDA 版约 2.9 GB，另外还会安装其他依赖。失败时窗口保留错误信息，可查看 `outputs/setup/` 的日志，修复网络或磁盘空间后再次双击重试。已下载的有效文件和 pip 缓存会复用，CUDA 分块下载支持续传。重复双击时，后一个安装过程会等待前一个完成。

缺失 Python 时安装的是项目内的 **CPython 3.11.16 x64**，来自 [Astral python-build-standalone 20260901](https://github.com/astral-sh/python-build-standalone/releases/tag/20260901)，存放在 `.runtime/`。下载地址、文件大小与 SHA-256 固定在 `configs/bootstrap.json`，校验通过后才解压运行。安装不要求管理员权限，不修改系统 Python、PATH 或注册表。无法运行的旧 `.venv` 会先备份为 `.venv.backup-*`，再创建新环境。

自动安装覆盖 Python 和程序依赖。模型权重、微调检查点需要单独准备；没有检查点时网页进入等待状态。

工具会从 `outputs/decision-full` 选择步数最大的完整微调断点。没有断点时，网页显示训练进度，并等待首个完整断点出现后自动加载。不会把原始基础模型或未保存完整的文件当作微调模型。

## 在网页中使用

1. 等页面显示“模型已就绪”。
2. 使用“表单”填写状态、判断类型、问题和候选；也可以选意图识别、情感分类或混合判断示例。
3. 点击“开始判断”，查看分类概率、等级评分或命题成立概率。
4. 如需结构化状态、多个独立问题或自定义是非定义，切换到“请求 JSON”。返回结果保留 Jev 兼容格式，无 `confidence` 字段。

分类候选每行写 `名称 | 描述`；评分等级每行一个，按从低到高排列。评分从0开始，显示概率加权的期望分数。混合请求中的每个问题独立判断。页面支持复制完整响应及下载JSON结果。

## 加载与退出

- 默认自动选择设备。本项目训练仍在运行时使用CPU；训练结束且显卡有足够空闲显存时优先使用显卡。CPU判断可能较慢。
- 新断点保存后，页面会出现“有新断点 · 加载”按钮；点击后切换到最新模型。也可以选择运行设备，再点击“加载最新模型”。
- 重复双击启动工具会打开已有服务，不会重复加载多个模型。
- 点击网页右上角“退出工具”，或双击 **关闭决策模型.cmd**，结束网页模型服务并释放其资源。训练任务不受影响。
- 只关闭浏览器页面不会结束后台服务。

默认地址为 `http://127.0.0.1:8765`。端口被占用时自动改用空闲端口，并打开正确地址。服务仅监听本机，网页资源不依赖外网。

## 文件位置

- `outputs/webapp/server.log`：启动、加载和错误日志。
- `outputs/setup/setup-*.log`：环境检查、下载和安装日志。
- `outputs/setup/requirements-installed.txt`：最近一次安装后的依赖版本快照。
- `.runtime/`：项目内 Python、下载缓存、环境检查结果及安装锁。
- `outputs/webapp/server.json`：当前本机服务端口、进程及本机会话信息。
- `outputs/decision-full/checkpoint-*`：训练产生的断点；只有含 `COMPLETE` 且必要文件齐备的目录才可加载。
- `reports/webapp-launcher-check.json`：启动、关闭和端口占用的实际检查结果。
- `reports/bootstrap-check.json`：从无 Python 开始安装、缺失依赖修复、重复启动与网页打开的实测记录。

## 只准备环境或指定运行版本

仅安装环境、不打开网页：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup.ps1
```

需要指定 CPU 或 CUDA 版 PyTorch 时，分别追加 `-Torch cpu` 或 `-Torch cuda`。`-Python` 可指定已有的 Python 3.11 x64 路径，`-IndexUrl` 可指定 Python 依赖镜像。训练仍需要可用的 NVIDIA CUDA 显卡；一键网页推理支持 CPU。
